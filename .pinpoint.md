# PinPoint Context — IGA Marketing

- Framework: Astro 5.7
- Pages: src/pages/
- Components: src/components/
- Layouts: src/layouts/ (if present)
- Styles: Tailwind CSS via @astrojs/tailwind
- Build command: astro build (npm run build)
- Output directory: dist/
- Deployment: GitHub Pages from PerceptumNL/iga-website (main branch via deploy.yml workflow)
- Live URL: https://perceptumnl.github.io/iga-website/ (custom domain igamarketing.com layered on top via DNS)
- Base path: /iga-website/ (set in astro.config.mjs)
- Notes: Static site, no server-side rendering. Sitemap auto-generated by @astrojs/sitemap. Production builds must NOT include the Pinpoint widget — it only loads on previews where PINPOINT_PREVIEW env var is set during the build.
